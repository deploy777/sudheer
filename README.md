# MS. — Hospitality Portfolio
## Miriyala Sudheer | Hospitality General Cashier & Hotel Cashier Manager
### Featuring Fullscreen 3D Hotel Entrance Doors, Dark Raw & Rustic Aesthetic, and 3D Retro Printer

A modern, recruiter-focused luxury hospitality portfolio website crafted specifically for hotel HR managers, General Managers, and hospitality finance directors.

---

### 🌟 Key Interactive Features
1. **3D Grand Hotel Double Glass Doors Entrance**:
   - 3D perspective chamber with fluted glass panels and brushed brass frames.
   - Interactive double French doors that swing open in 3D, accompanied by a synthesized 5-star hotel lobby chime.
   - Fully optimized for mobile viewports with smooth horizontal parting.
2. **Raw & Rustic Dark Theme Luxury Interior**:
   - Built on a palette of raw charcoal slate (`#0D0C0A`), smoked walnut timber (`#141210`), weathered stone glass (`rgba(24, 22, 19, 0.85)`), and antique burnished brass (`#C6A46A`).
   - High-contrast, easy-to-read typography in limestone ivory and warm parchment.
3. **3D Retro Dot-Matrix Printer for Resume Download**:
   - Interactive 3D retro computer printer modal.
   - Continuous tractor-feed perforated paper simulation with line-by-line print head reveal.
   - Built-in zero-dependency Web Audio API staccato print head and typewriter bell synthesizer.
   - Automatic verified PDF download (`Miriyala_Sudheer_Hospitality_General_Cashier_Resume.pdf`).
4. **Interactive Modals & Lightbox**:
   - Detailed competency modal inspector for cashiering SOPs, cash handling, and safe custody.
   - Image lightbox previews for all 3 hotel properties.
   - Fast-action recruiter inquiry email generator and WhatsApp direct chat.

### 🚀 Deployment Instructions (Vercel)
1. **Import Git Repository in Vercel**:
   - Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
   - Select the GitHub repository `deploy777/sudheer`.
   - Framework Preset: **Other** (Pure static site).
   - Root Directory: `./` (default).
   - Click **Deploy**.
2. **Vercel CLI**:
   - Run `vercel` in this directory and follow the prompts.
